# Certified abstract of judgment

Reviewed September 21, 2026. Command `/abstract`. Outcome: `CLERK_ISSUED_PROCESS`.

## Decision and boundary

Obtain the actual certified abstract from the issuing clerk and follow receiving-court docketing requirements. Virginia Code § 8.01-389 addresses judicial records as evidence; the clerk’s certification cannot be created by counsel’s template. The old CC-1407 catalog reference is a service form, not an abstract. No court process was generated.
