## Requirements and source-supported constraints

Rule 3:19 distinguishes default status, relief before judgment, a motion for judgment with notice, unliquidated damages and relief after judgment.

## Conditional decisions and boundaries

A request for entry of default is not a genuine alias for a motion awarding judgment. Route to the existing reviewed judgment template only after the requested relief is established.
