# INTERROGATORIES CONCERNING TRIAL EXPERTS
To: [RESPONDING PARTY], through [COUNSEL]
[REQUESTING PARTY] serves these interrogatories under Rules 4:1(b)(4)(A)(i) and 4:8. The response deadline is [VERIFIED DATE UNDER RULES AND ENTERED ORDERS]. The applicable expert-disclosure order is [ORDER DATE AND PROVISION, IF ANY].
Restate each question and answer separately and fully under oath. State each objection specifically and answer any portion not objected to. Supplement as required by Rule 4:1(e) and applicable orders. These requests concern expected trial experts, not undisclosed consulting experts, protected drafts or privileged attorney communications.
1. Identify each person whom you expect to call as an expert witness at trial.
2. For each identified person, state the subject matter on which the expert is expected to testify.
3. For each identified person, state the substance of the facts to which the expert is expected to testify.
4. For each identified person, state the substance of the opinions to which the expert is expected to testify.
5. For each opinion, summarize the grounds supporting that opinion.
These interrogatories are served subject to the cumulative limit in Rule 4:8(g) and any leave or order applicable to this case. The prior interrogatory count and any leave relied upon are [COUNT AND ORDER].
